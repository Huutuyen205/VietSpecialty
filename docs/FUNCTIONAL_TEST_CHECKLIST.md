### 1.3 CSRF & Exception Handling Contract for M2 Execution
- **CSRF Token (`_csrf` / `X-CSRF-TOKEN`):** Enabled globally for all `POST` / `PUT` / `DELETE` requests **except** `/api/payment/vnpay/ipn`, `/api/chat/**`, and `/api/chatbot/**` (`SecurityConfig.java:69-70`).
- **Exception Mapping:** `@RestController` routes use `GlobalApiExceptionHandler` (returns `ErrorCode.httpStatus`, e.g., `401`/`403`/`404`/`400` JSON `ApiResponse`). `@Controller` web routes use `GlobalWebExceptionHandler` (maps uncaught `BusinessException` to HTTP `400` rendering `error/500.html` unless caught inside the controller for flash redirect).
- **Role Hierarchy:** `ROLE_SELLER` implies `ROLE_USER`. **`ROLE_ADMIN` does NOT imply `ROLE_USER` or `ROLE_SELLER`.**
